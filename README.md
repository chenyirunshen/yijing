## 三分钟上手 · 到底怎么用

### 第 0 步：打开

浏览器访问 **https://chenyirunshen.github.io/yijing/** ，你会看到底部两个标签：**起卦** 和 **六十四卦**。

### 第 1 步：静心想事（别跳过）

心里**只放一件具体的事**。问题越具体，卦越准。

- ❌ 模糊：「我今年运势怎么样」
- ✅ 具体：「这份新工作要不要接」「这个项目现在该不该推进」「和 XX 的关系要不要再争取」

### 第 2 步：起卦

在「起卦」页选一种方式：

| 方式 | 操作 | 什么时候用 |
|---|---|---|
| **金钱卦** | 点「摇卦」，三枚铜钱翻转，自下而上摇**六次** | 正经问事，默认用这个 |
| **数字** | 心里想两个数，随手写下看到的也行 | 手边没有工具、临时起意 |
| **时间** | 点一下，自动取当下年月日时 | 「问事之时即起卦之时」，最贴当下 |
| **手动** | 自己选上下卦和动爻 | 已经知道卦名，只想看详解 |

### 第 3 步：看结果

卦成之后，从上往下这样读：

1. **本卦 → 变卦**：左边是你现在的处境，右边是事情发展下去的走向。
   **红框标出来的爻就是「动爻」**——它是这件事的关键变量。
2. **断法**：告诉你这一卦该看哪一句（动了几个爻，取用规则不同，程序已自动处理）。
3. **卦辞 / 爻辞**：《周易》原文 + 白话。**白话是给你理解用的，原文才是主体。**
4. **王弼义理**：这一卦的深层义理，点出「卦主」在哪一爻——读懂它，比背卦辞有用。
5. **现代案例**：落到现实里，这一卦具体对应的处境。

> 拿不准就看最后的 **该进 / 该退 / 该等** 三个字，那是最直接的行动建议。

### 第 4 步：深入查 / 回头看

- 点结果页底部「查看完整详解」→ 看这一卦六爻全部爻辞
- 点底部「**六十四卦**」→ 搜索或筛选，比如直接搜「感情」「晋升」「困境」「创业」
- 「起卦」页往下拉是**卦历**，起过的卦自动记着，点一下能回看

## 问事的规矩（可读可不读，但挺重要）

《易经》蒙卦卦辞早就把话说透了：**「初筮告，再三渎，渎则不告。」**

| 该做 | 别做 |
|---|---|
| 一事一问，问题具体 | 一次问好几件、问题大而空 |
| 第一卦就是你的卦，相信它 | 结果不满意就反复重摇，摇到满意为止 |
| 问自己的事 | 替别人占、打听别人的隐私和命运 |
| 问「该怎么做」 | 问生死吉凶、问违法的事 |

> 《易经》是**决策的参考、自省的镜子，不是判决书**。
> 它帮你把处境看清楚，最终的选择永远在你自己手里。

## 功能速览

### 一、起卦（四种方式）

**铜钱规则**（依朱熹《易学启蒙》）：字面＝阴（2），背面＝阳（3）。
三背＝老阳 9（动爻 ○）／三字＝老阴 6（动爻 ×）／两背一字＝少阴 8／一背两字＝少阳 7。

### 二、解卦（自动按动爻数取用）

严格依朱熹《易学启蒙》的变卦规则，不是随便挑一句：

| 动爻数 | 取用什么 |
|---|---|
| 0 个 | 本卦卦辞 |
| 1 个 | 本卦该爻爻辞 |
| 2 个 | 本卦两爻辞，以上爻为主 |
| 3 个 | 本卦卦辞为主 + 变卦卦辞为辅（现状 → 结局） |
| 4 个 | 变卦的两个静爻，以下爻为主 |
| 5 个 | 变卦唯一的静爻 |
| 6 个 | 变卦卦辞（乾坤并参用九／用六） |

### 三、六十四卦速查

- 实时搜索：卦名、关键词、白话处境都能搜（试搜「感情」「晋升」「困境」「创业」）
- 标签筛选：上经／下经／感情／职场／财物／困境／决断／人际／修己／积累／家庭／变革／学习／突发
- 点任意一卦进**详解页**：卦辞、大象传、六爻爻辞（原文 + 白话）、王弼义理（含卦主）、现代案例

### 四、卦历

每次起卦自动存在本地（localStorage，最多 20 条，**不上传任何服务器**）。

## 部署到 GitHub Pages

本仓库已开启 Pages，源为 `main` 分支根目录，线上地址就是开头那个。
若你想 fork 到自己名下重新部署：

### 懒人方式：双击 `publish-github.bat`

仓库根目录下的 **`publish-github.bat`**，双击就能跑完整个流程：
登录 → 提交 → 建仓库 → 推送 → 开 Pages。屏幕上有提示，跟着走就行。
（仅 Windows。脚本可重复运行，之后改动了内容再双击一次即为增量更新。）

### 手动方式（3 步）

1. 新建仓库，把 `index.html`、`data.js`、`README.md` 三个文件丢进去
2. 仓库 **Settings → Pages → Source** 选 `main` 分支，根目录 `/`
3. 等一两分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`

**本地预览**：直接双击 `index.html` 即可（无需本地服务器）。

## 数据来源与免责

- 卦名、卦序依《周易》**通行本（文王卦序）**；卦辞、爻辞、大象传为通行本原文。
