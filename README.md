# 易 · 起卦与六十四卦速查

一个纯前端、零依赖的单页《易经》工具：能起卦、能解卦、能查六十四卦详解。
手机优先设计，直接丢到 GitHub Pages 就能用，无需构建、无需服务器。

---

## 能干什么

### 一、起卦（四种方式）

| 方式 | 怎么用 | 适合什么场景 |
|---|---|---|
| **金钱卦** | 点击摇卦，三枚铜钱自下而上摇六次，有翻转动画 | 最传统、最正统的起卦法，正经问事用这个 |
| **数字** | 心里想两个数，或随手写下看到的两个数字 | 临时起意、手边没有铜钱 |
| **时间** | 自动读取当下年月日时起卦 | 「问事之时即起卦之时」，最贴合当下 |
| **手动** | 直接选上下卦和动爻 | 已知卦名，只想看详解 |

**铜钱规则**（依朱熹《易学启蒙》）：字面＝阴（2），背面＝阳（3）。
三背＝老阳 9（动爻 ○）／三字＝老阴 6（动爻 ×）／两背一字＝少阴 8／一背两字＝少阳 7。

### 二、解卦（自动按动爻数取用）

严格依朱熹《易学启蒙》的变卦规则，不是随便挑一句：

| 动爻数 | 取用什么 |
|---|---|
| 0 个 | 本卦卦辞 |
| 1 个 | 本卦该爻爻辞 |
| 2 个 | 本卦两爻辞，以上爻为主 |
| 3 个 | 本卦卦辞为主 + 变卦卦辞为辅（现状 → 结局） |
| 4 个 | 变卦的两个静爻，以下爻为主 |
| 5 个 | 变卦唯一的静爻 |
| 6 个 | 变卦卦辞（乾坤并参用九／用六） |

结果页会给出：本卦卦画 → 变卦卦画（动爻标红）、断法依据、卦辞／爻辞原文 + 白话、**王弼义理**解读、现代案例。

### 三、六十四卦速查

- 实时搜索：卦名、关键词、白话处境都能搜（试搜「感情」「晋升」「困境」「创业」）
- 标签筛选：上经／下经／感情／职场／财物／困境／决断／人际／修己／积累／家庭／变革／学习／突发
- 点任意一卦进**详解页**：卦辞、大象传、六爻爻辞（原文 + 白话）、王弼义理（含卦主）、现代案例

### 四、卦历

每次起卦自动存在本地（localStorage，最多 20 条，不上传任何服务器）。

## 部署到 GitHub Pages

### 懒人方式：双击 `publish-github.bat`

仓库根目录下的 **`publish-github.bat`**，双击就能跑完整个流程：
登录 → 提交 → 建仓库 → 推送 → 开 Pages。屏幕上有中文提示，跟着走就行。
（仅 Windows。脚本可重复运行，之后改动了内容再双击一次即为增量更新。）

### 手动方式（3 步）

1. 新建仓库，把 `index.html`、`data.js`、`README.md` 三个文件丢进去
2. 仓库 **Settings → Pages → Source** 选 `main` 分支，根目录 `/`
3. 等一两分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`

想手机用：把网址加到主屏，就是一个 App。

**本地预览**：直接双击 `index.html` 即可（无需本地服务器）。

## 文件结构

```
index.html   界面 + 起卦引擎 + 解卦逻辑（含全部 CSS/JS）
data.js      六十四卦数据：卦辞、大象传、六爻爻辞(原文+白话)、王弼义理、卦主、现代案例

```

想改内容，只动 `data.js` 就行，不用碰 `index.html`。

## 数据来源与免责

- 卦名、卦序依《周易》**通行本（文王卦序）**；卦辞、爻辞、大象传为通行本原文。
- 「王弼义理」是**依王弼《周易注》义理派思路所作的现代诠释**，不是逐字原文引用。王弼的核心方法（一爻为主、得意忘象、刚柔当位、时与位）已体现在每条解读中，深研请回原典。
- 六爻白话、现代案例为便于理解所作的现代转译，属一家之言。
