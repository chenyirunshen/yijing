## 三分钟上手 · 到底怎么用

### 第 0 步：打开

浏览器访问 **https://chenyirunshen.github.io/yijing/** ，你会看到底部两个标签：**起卦** 和 **六十四卦**。

### 第 1 步：静心想事（别跳过）

心里**只放一件具体的事**。问题越具体，卦越准。

- ❌ 模糊：「我今年运势怎么样」
- ✅ 具体：「这份新工作要不要接」「这个项目现在该不该推进」「和 XX 的关系要不要再争取」

### 第 2 步：写下你要问的事，占这一卦

底部第一个标签是 **「问事」**（默认就在这页）：

1. 文本框里写下你要问的事——越具体越好
2. 选一个类型（事业 / 感情 / 财运 / 人际 / 决断），**不选也会自动判断**
3. 点 **「占 这 一 卦」**

### 第 3 步：看给你的六段解读

结果页从上往下依次是：

| # | 这一段讲什么 |
|---|---|
| 1 | **你问的事** —— 回显你的问题，确认没理解错 |
| 2 | **得到这一卦** —— 本卦 → 变卦，红框是动爻，还有卦性徽章（上吉 / 吉 / 平 / 吝 / 凶） |
| 3 | **这一卦在说什么** —— 卦辞、大象传、这一卦的核心处境 |
| 4 | **落到你这件事上** —— ⭐ 结合你写的那件事 + 你选的类型，给出**针对性解读**，并附动爻提醒 |
| 5 | **你现在可以这样做** —— 三条具体可执行的行动 + 总的方向（进 / 退 / 等） |
| 6 | **王弼怎么看** —— 这一卦的深层义理 |

> 赶时间就直接看第 **4** 段和第 **5** 段——那是专门针对你这件事写的。

### 第 4 步：回头看

- **问事记录**：问过的事都存着（连问题原文一起），点一下能重新打开那次解读
- **卦典**（底部第三个标签）：直接搜索或筛选查某一卦，比如搜「感情」「晋升」「困境」「创业」
- **起卦**（中间标签）：想按传统方式摇铜钱、用数字或时间起卦，来这里

> **「问事」和「起卦」的区别**：问事是「傻瓜模式」——写问题、点一下、给你解读；
> 起卦保留了完整的传统起卦流程和解卦规则（动爻数决定取用哪一句），适合想看得更细的人。

## 问事的规矩（可读可不读，但挺重要）

《易经》蒙卦卦辞早就把话说透了：**「初筮告，再三渎，渎则不告。」**

| 该做 | 别做 |
|---|---|
| 一事一问，问题具体 | 一次问好几件、问题大而空 |
| 第一卦就是你的卦，相信它 | 结果不满意就反复重摇，摇到满意为止 |
| 问自己的事 | 替别人占、打听别人的隐私和命运 |
| 问「该怎么做」 | 问生死吉凶、问违法的事 |

> 《易经》是**决策的参考、自省的镜子，不是判决书**。
> 它帮你把处境看清楚，最终的选择永远在你自己手里。

## 功能速览

### 〇、问事（一键起卦 + 针对性解读）

写下你要问的事 → 一键成卦 → 得到六段解读。核心是第 4 段「落到你这件事上」：
程序会先判断你的问题属于哪一类（事业 / 感情 / 财运 / 人际 / 决断，可手动改），
然后从 **64 卦 × 5 类 = 320 条**解读里取出对应的那一条——不是套话，是具体到「该止损还是该等」的建议。

最后给三条可执行动作，外加一个总方向（进 / 退 / 等）。

### 一、起卦（四种方式）

**铜钱规则**（依朱熹《易学启蒙》）：字面＝阴（2），背面＝阳（3）。
三背＝老阳 9（动爻 ○）／三字＝老阴 6（动爻 ×）／两背一字＝少阴 8／一背两字＝少阳 7。

### 二、解卦（自动按动爻数取用）

严格依朱熹《易学启蒙》的变卦规则，不是随便挑一句：

| 动爻数 | 取用什么 |
|---|---|
| 0 个 | 本卦卦辞 |
| 1 个 | 本卦该爻爻辞 |
| 2 个 | 本卦两爻辞，以上爻为主 |
| 3 个 | 本卦卦辞为主 + 变卦卦辞为辅（现状 → 结局） |
| 4 个 | 变卦的两个静爻，以下爻为主 |
| 5 个 | 变卦唯一的静爻 |
| 6 个 | 变卦卦辞（乾坤并参用九／用六） |

### 三、六十四卦速查

- 实时搜索：卦名、关键词、白话处境都能搜（试搜「感情」「晋升」「困境」「创业」）
- 标签筛选：上经／下经／感情／职场／财物／困境／决断／人际／修己／积累／家庭／变革／学习／突发
- 点任意一卦进**详解页**：卦辞、大象传、六爻爻辞（原文 + 白话）、王弼义理（含卦主）、现代案例

### 四、卦历

每次起卦自动存在本地（localStorage，最多 20 条，**不上传任何服务器**）。

## 部署到 GitHub Pages

本仓库已开启 Pages，源为 `main` 分支根目录，线上地址就是开头那个。
若你想 fork 到自己名下重新部署：

### 懒人方式：双击 `publish-github.bat`

仓库根目录下的 **`publish-github.bat`**，双击就能跑完整个流程：
登录 → 提交 → 建仓库 → 推送 → 开 Pages。屏幕上有提示，跟着走就行。
（仅 Windows。脚本可重复运行，之后改动了内容再双击一次即为增量更新。）

### 手动方式（3 步）

1. 新建仓库，把 `index.html`、`data.js`、`README.md` 三个文件丢进去
2. 仓库 **Settings → Pages → Source** 选 `main` 分支，根目录 `/`
3. 等一两分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`

**本地预览**：直接双击 `index.html` 即可（无需本地服务器）。

## 文件结构

```
index.html   界面 + 起卦引擎 + 解卦逻辑 + 问事解读（含全部 CSS/JS）
data.js      六十四卦数据：卦辞、大象传、六爻爻辞(原文+白话)、王弼义理、卦主、现代案例
advice.js    六十四卦针对性解读：卦性 + 五类问题解读(320条) + 每卦三条行动建议
README.md    本文件
publish-github.bat  一键发布脚本（Windows）
```

想改内容，只动 `data.js` 就行，不用碰 `index.html`。改完双击 `publish-github.bat` 即完成更新推送。
